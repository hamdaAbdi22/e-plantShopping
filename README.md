Paradise Nursery - Online Plant Shopping Application

Project Overview

Paradise Nursery is a front-end online shopping application designed to allow users to browse and shop for a variety of houseplants. The application provides a simple and user-friendly interface where customers can explore plants, add their favorite plants to a shopping cart, and manage their purchases.

This project is developed as part of a final project to demonstrate front-end web development skills using React.

Application Pages

The application consists of three main pages:

1. Landing Page
   - Introduces Paradise Nursery.
   - Provides a welcome message and an option to start shopping.

2. Product Listing Page
   - Displays a variety of houseplants.
   - Shows plant information and prices.
   - Allows users to add plants to the shopping cart.

3. Shopping Cart Page
   - Displays the selected plants.
   - Shows the quantity and price of each item.
   - Allows users to increase or decrease item quantities.
   - Allows users to remove items from the cart.
   - Displays the total cost of the items in the cart.
   - Provides a checkout option.

Technologies Used

- React
- JavaScript
- HTML5
- CSS3
- Vite

Key Features

- Browse a variety of houseplants.
- Add plants to the shopping cart.
- Manage product quantities.
- Remove products from the cart.
- Calculate the total shopping cost.
- Navigate between the landing page, product listing page, and shopping cart page.

Installation and Setup

Follow these steps to run the application locally.

1. Clone the repository:

   bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   

2. Navigate to the project directory:

   bash
   cd e-plantShopping
   

3. Install the dependencies:

   bash
   npm install
   

4. Start the development server:

   bash
   npm run dev


5. Open the local URL displayed in your terminal to view the application.
project Purpose
